# System Monitoring Dashboard (Bash)

Lightweight Bash script for quick system health, storage, and network diagnostics on macOS and Linux. Developed as a practical mini-project to build skills in Linux CLI and systems administration.

## Author
Vitalii Stetsenko  
B.Sc. Computer Science (Infrastructure) Student (TU857) at Technological University Dublin (TU Dublin)

## Features
- **System Info:** Displays current user, hostname, and system uptime.
- **Disk Usage:** Parses root storage metrics via core utilities.
- **Network Status:** Retrieves active local IP address.
- **Internet Check:** Executes ICMP ping to verify live external connectivity.

## Tech Stack
- Language: Bash Shell Scripting
- Core Utilities: awk, df, ping, ipconfig, whoami, uptime
